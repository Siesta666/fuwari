# 方程引入

物理问题中，我们经常需要求解拉普拉斯方程、泊松方程、波动方程，这一些方程都有一个共同点，都有拉普拉斯算子，也就是 $\nabla^{2}$，一般的直角坐标系的**拉普拉斯算子**可以直接使用分离变量法进行求解，那在柱坐标、球坐标中也是如此：

先来看球坐标的拉普拉斯算子：
$$
\nabla^{2} = \frac{1}{r^{2}}\frac{ \partial  }{ \partial r } \left( r^{2}\frac{ \partial  }{ \partial r }  \right) + \frac{1}{r^{2}\sin \theta}\frac{ \partial  }{ \partial \theta } \left( \sin \theta \frac{ \partial  }{ \partial \theta }  \right)+\frac{1}{r^{2}\sin^{2}\theta}\frac{ \partial ^{2} }{ \partial \varphi^{2} } 
$$
柱坐标的拉普拉斯算子：
$$
\nabla ^{2} = \frac{1}{r}\frac{ \partial  }{ \partial r } \left( r\frac{ \partial  }{ \partial r }  \right) + \frac{1}{r}\frac{ \partial^{2}  }{ \partial \theta^{2} } + \frac{ \partial^{2}  }{ \partial z^{2} } 
$$
拿拉普拉斯方程举例子，球坐标的拉普拉斯方程可以表示为，设解为 $u(r,\theta,\varphi) = R(r)\Theta(\theta)\Phi(\varphi)$
$$
\frac{1}{r^{2}R}\frac{ \partial  }{ \partial r } \left( r^{2}\frac{ \partial R }{ \partial r }  \right) + \frac{1}{r^{2}\sin \theta \,\Theta}\frac{ \partial  }{ \partial \theta } \left( \sin \theta \frac{ \partial \Theta }{ \partial \theta }  \right)+\frac{1}{r^{2}\sin^{2}\theta \, \Phi}\frac{ \partial ^{2} \Phi }{ \partial \varphi^{2}} = 0
$$
设：
$$
\begin{align}
\frac{ \partial ^{2}\Phi }{ \partial \varphi^{2} }  &= -m^{2}\Phi \\
\frac{ \partial  }{ \partial r } \left( r^{2}\frac{ \partial R }{ \partial r }  \right) &= l(l+1) R
\end{align}
$$
得到**极角方程**：
$$
\frac{1}{\sin \theta}\frac{ \partial  }{ \partial \theta } \left( \sin \theta \frac{ \partial \Theta }{ \partial \theta }  \right) = \left(\frac{1}{\sin^{2}\theta}m^{2} - l(l+1)\right)\Theta
$$
这就是球坐标下的分离变量法得到的三个分量方程，我们称极角方程为**连带勒让德方程**，当 $m = 0$
方程简化为**勒让德方程**：
 $$
 \frac{1}{\sin \theta}\frac{ \partial  }{ \partial \theta } \left( \sin \theta \frac{ \partial \Theta }{ \partial \theta }  \right) +l(l+1)\Theta = 0
 $$
径向方向可以化简为：
 $$
 r^{2}\frac{ \partial ^{2}R }{ \partial r^{2} }  + 2r\frac{ \partial R }{ \partial r } - l(l+1)R = 0
 $$
 这是**欧拉方程**，可以直接写出解：
 $$
 R_{l}(r) = A_{l}\,r^{l} + B_{l}\,r^{-(l+1)}
 $$
 方位角部分是一个简单的**谐振子方程**，可以直接写出解：
$$
\Phi_{m}(\varphi) = A_{m}\cos m\varphi + B_{m}\sin m\varphi
$$
另外方位角部分有一个天然的周期限制条件：
$$
\Phi(\varphi + 2\pi) = \Phi(\varphi)
$$
这要求 $m$ 必须是一个整数，记住这个限制条件，后续会用到的。

要解这个拉普拉斯方程，相当于解极角部分的连带勒让德方程。

# 勒让德方程

要解连带勒让德方程，我们先来解简单一些的勒让德方程，也就是：
$$
 \frac{1}{\sin \theta}\frac{ \partial  }{ \partial \theta } \left( \sin \theta \frac{ \partial \Theta }{ \partial \theta }  \right) +l(l+1)\Theta = 0
 
$$
换元： $x= \cos \theta,\quad y = \Theta(\theta)$，得到：
$$
\frac{1}{1-x^{2}}y^{\prime\prime} - 2 x y^{\prime} + l(l+1)y = 0
$$
设级数解：$y = \sum C_{k}x^{C+k}$，代入得到系数递推方程：
$$
\begin{align}
C & = 0 \\
C_{k+2} &=(-1) \frac{(l-k)(l+k+1)}{(k+2)(k+1)}C_{k}
\end{align}
$$
发现偶数列和奇数列无关，那么解就可以表示成奇数列和偶数列的线性组合，对于任何一个 $l$ ，都存在数列满足递归。但是这里有一个问题，一般来看，如果这是一个无穷项级数，那么可以证明的是在 $x = 1$ 处级数趋向正无穷，这显然和物理事实不相符，那要让级数是一个有界值，必须让系数在某一点截断，也就是在此之后的系数递归均为0，也就是级数变成了一个多项式。要想实现这样的效果，必须要求 $l$ 为一个整数。比如 $l = 2$ ，那么偶数列会在 $C_{2}$ 处截断，即 $C_{4} = C_{6} = \dots= 0$

那么我们就确定了要想获得在物理意义上合理的数学解，就需要 $l$ 为一个整数，当 $l$ 为偶数，那为了保证级数有界，奇数列必须全为 $0$ 。

比如我们可以写出前面几个解：
$$
\begin{alignat}{2}
P_{0} &=1 \qquad \qquad \qquad &  &P_{1} =x\\
P_{2} &=3x^{2}-1 & &P_{3} = 5x^{3} - 3x
\end{alignat}
$$
如果告知了最高次幂的系数，那么整一个数列都是已知的了。那为了简化表达式，我们有一个规定：
$$
C_{l} = \frac{(2l)!}{2^{l}(l!)^{2}}
$$
后续计算出来的多项式满足 $P_{l}(1) = 1$，满足有界性。我们称这样子获得的多项式称为勒让德多项式：
$$
\begin{alignat}{2}
P_{0} &= 1 \qquad \qquad\qquad & P_{1} &= x \\
P_{2} &= \frac{1}{2}(3x^{2}-1) & P_{3} &= \frac{1}{2}(5x^{3}-3x)
\end{alignat}
$$
当我们定义内积为：$f \cdot g = \int_{-1}^{1}f(x)g(x)\mathrm{d}x$ 时，勒让德多项式是成交的：
$$
\int  _{-1}^{1}P_{n}P_{m}\, dx = \sqrt{ \frac{2}{2n+1} }\delta_{mn}
$$
另外我们也可以证明勒让德多项式也是一个完备的函数集，可以用勒让德函数来表示任何平方可积函数，类似傅里叶级数。

回到勒让德方程，我们写出解：
$$
\Theta(\theta) = A_{l}P_{l}(\cos \theta)
$$
## 连带勒让德函数

我们原本的方程为
$$
\frac{1}{\sin \theta}\frac{ \partial  }{ \partial \theta } \left( \sin \theta \frac{ \partial \Theta }{ \partial \theta }  \right) = \left(\frac{1}{\sin^{2}\theta}m^{2} - l(l+1)\right)\Theta
$$
这是**连带勒让德方程**，其中 $m$ 是一个整数。利用相同的换元得到化简之后的方程：
$$
\frac{1}{1-x^{2}}y^{\prime\prime} - 2 x y^{\prime} + \left( l(l+1) - \frac{m^{2}}{1-x^{2}} \right)y = 0
$$
为了解这个方程，我们需要先对勒让德方程求 $m$ 阶导数，然后进行换元，最后得到解：
$$
P_{l}^{m}(x) = (-1)^{|m|}(1-x^{2})^{|m|/2}P_{\text{ }l}^{(m)}(x)
$$
带回到原本的方程中：
$$
\Theta(\theta) = A_{l}P_{l}^{m}(\cos \theta)
$$

## 球谐函数

将方位角和极角两部分结合起来就得到了球谐函数 $Y_{l}^{m}(\theta ,\varphi)$
$$
Y^{m}_{l}(\theta, \varphi) = \varepsilon A_{lm}P_{l}^{m}(\cos \theta)e^{im\varphi}
$$
其中 $A_{lm}$ 是归一化系数，$\varepsilon$ 是相位规定系数

## 拉普拉斯方程的解

最后和径向部分结合起来得到拉普拉斯方程的通解：
$$
y(r,\theta,\varphi) = \sum_{l,m}(A_{l}\,r^{l}+B_{l}\,r^{-(l+1)})Y_{lm}(\theta,\varphi)
$$
